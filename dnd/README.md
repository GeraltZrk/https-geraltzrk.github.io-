# 安本纳尔：命运之骰

一个粉丝做的跑团模拟器，世界观是 P 社模组 Anbennar。浏览器里直接玩，手机、PC、Mac 都行，不用安装，也不用联网存档。

非官方作品。世界观和美术归 Anbennar 制作组和各位原作者，详见游戏里的“关于”。

## 三个剧本

| 开局 | 剧本 | 对应模组 |
|---|---|---|
| 1022 年 | 《无冕之年》 | 十字军之王 3 模组开局 |
| 1444 年 | 《送神》 | 欧陆风云 4 模组开局 |
| 1820 年 | 《泪尽》 | 维多利亚 3 模组开局（模组的实际开局年是 1820，不是原版的 1836） |

每个剧本先选出身（国家或族群）、阵营，再捏人：19 个种族、13 个职业、19 种背景，属性可以点数购买、标准数组或者掷骰。

## 怎么玩

- 线上：仓库的 GitHub Pages 地址后面加 `/dnd/`。
- 本地：在这个目录里起一个静态服务器，比如 `python3 -m http.server 8765`，然后开 `http://localhost:8765/`。直接双击 `index.html` 不行，浏览器不让本地文件加载模块。
- 手机：用浏览器打开后“添加到主屏幕”，之后像 App 一样全屏打开，离线也能玩。

存档在浏览器本地，共有自动档和手动档位。换设备的话，在“系统 → 存档”里导出一串存档码，到另一台设备上导入。

## 作弊

菜单里的“作弊”随时能开，不影响存档：

- **神格**：让主角升神、永生。升神以后剧情文字、选项和别人的反应都会跟着变，战斗里敌人会被神威压住，另有三个神术。可以给自己起神名、选神职。
- **开关**：无敌、一击必杀、无限资源、检定必成、固定 d20 点数、解锁全部选项、显示隐藏选项、跳过战斗、买东西不花钱。
- **角色 / 物品 / 队伍**：改等级、属性、金币、职业和种族，学会任意能力，拿任意物品，让任意同伴入队。
- **世界 / 剧情**：改世界局势、各方声望、剧情标记，跳到任意场景或章节，直接看结局，退回上一步。
- **战斗**：直接获胜、全队回满。

新开游戏时也可以直接勾“以神之身开局”。

## 目录

```
index.html, css/, sw.js     页面、样式、离线缓存
js/core/                    规则、状态、条件与效果、剧情引擎、战斗
js/ui/                      各个界面
js/data/                    职业、种族、法术、物品、怪物
js/data/scenarios/<id>/     剧本：BIBLE.md 是设定和场景表，其余是场景数据
assets/                     从模组仓库导出的载入图、事件插画、头像、国旗
docs/                       写内容用的格式和文风说明，资料研究和剧本提案
tools/                      校验、自动试玩、美术导出脚本
```

改完内容跑一遍：

```
node tools/test-core.mjs          # 规则和引擎的单元测试
node tools/validate.mjs           # 检查所有剧本的引用、条件、效果和文风
node tools/autoplay.mjs s1444     # 随机走完整个剧本若干遍，找死路
node tools/e2e-smoke.mjs <地址> <截图目录> <剧本序号0-2> <步数>   # 用浏览器在桌面和手机尺寸各走一遍
```
