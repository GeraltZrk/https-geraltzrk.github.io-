# 1022《无冕之年》速览（用来核对事实和补交代，不要把这里的句子照抄进正文）

**前提**：灰元 1022 年。前一年，术士王（黑卡斯塔诺的皇帝卡斯坦五十三世）在沼泽堡被五国联军击败，砍倒他的是克拉丽蒙德。五家签了《安本科斯特条约》。玩家受命担任“监誓人”，带着一枚印去见证各家履约，这枚印也可能被人借去给出兵正名。故事跨三十一年。

**关键概念**
- 慑心术和受慑者：术士王能让人照他的意思行事，事后毫无记忆。当年被他慑住的老兵身上还留着旧法术，有人用军营里的“旧口令”重新驱使他们（驯师梅尔科尔，他的老师亚科布）。受慑者发作时眼睛睁着，眼神是空的，像梦游。
- 验心：法师用法术查看一个人记得的事，用来判断他做某件事时是不是自己做的主。
- 试炼山和誓石：登上试炼山、在誓石上立誓的人就是皇帝，帝号“卡斯坦”。术士王在誓石里留下半句没说完的咒，谁在修好的石头上立誓，就被这半句咒套住，书里把这叫“缰绳”。
- 白年：1040 年起的瘟疫，死人会坐起来咬人，人类病得重，精灵病得轻。造瘟疫的是“亵渎者”坎雷克，一个巫妖。他那本拴着死人魂魄的名册就是他的命匣。渡鸦先知会十九年前就预见了这场瘟疫，却没有说。
- 泛神会议：各家神殿开会议定谁算神。

**各幕**：序章（五种出身：达梅里亚月庭、洛伦特玫瑰摄政、乌霜边区黑龙、伊贝瓦尔精灵、威克斯幼主之家）→ 第一幕《谁的手》（查受慑者行凶的幕后）→ 第二幕《地砖下的皇帝》（五十三世的遗体、试炼山、誓石）→ 间幕《十六年》→ 第三幕（1040 年白年瘟疫、逐精灵令、渡鸦山）→ 第四幕《玫瑰与月的婚礼》（洛伦特的西洛瑞尔家与达梅里亚的西尔穆纳家联姻。此前比武会上，达梅里亚的克雷格一枪刺死了洛伦特国王鲁本。还要定讨伐坎雷克的十字军章程）→ 间幕《十二个冬天》→ 终章《最后一个冬天》（进沼地讨伐坎雷克，谁来付撕掉名册那一页的代价）。

**同伴**：卡斯坦（鹰身女妖，五十三世没上谱的女儿，自称五十四世）；巴里（年轻的精灵，爱下厨，为人宽厚）；薇齐娜（渡鸦先知会的预言者，说话爱留余地：“要是……，我说的是要是”）；瓦勒兰（恩特本的骑士，洛伦特纯血派出身，对精灵有成见，说话带刺）。

**阵营**：蓝宝石之眼（剑。凯伦·长枪定的规矩：打赢了给人留活路）；旧礼（冠。祭司替神加冕）；贤者门下（杖。法师要有人看着，最好由法师来看）。

**其他名词**：白银大队＝穆纳斯率领登陆坎诺的精灵军；月庭＝达梅里亚的宫廷；玫瑰摄政＝洛伦特的伊奥瑞尔太后一系；黑龙＝乌霜边区和黑卡斯塔诺的旧部；大墓地和收殓人＝威克斯边境替人下葬的行当；守砖人＝守着皇帝遗体所在地砖的人。
