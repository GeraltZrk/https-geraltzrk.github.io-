# 1444《送神》速览（用来核对事实和补交代，不要把这里的句子照抄进正文）

**前提**：灰元 1444 年，东坎诺（坎诺大陆东部，被兽人大军“绿潮”毁掉的故地）。卡斯托纳斯城的巷战里，红发女扈从科琳杀了兽人大酋长科尔古斯·杜坎森，自己也战死了。各营凑出一支收尸队，军令写的是“事毕为止”。玩家是其中一员。往后二十八年，这支队伍替几位没人肯安葬的死者料理后事，最后一位是诸神之王。

**各幕**
- 序章（五种出身）：科琳塔尔（追随科琳的队伍）；达梅里亚之子（紫丁香战争里输掉的月党流亡者）；皇帝的差事（替威克斯皇帝办事的密探）；负怨者兵团（替矮人讨祖上旧债的佣兵团）；退潮的人（杜坎森死后肤色不再变化的绿皮）。
- 第一幕《没人肯埋的兽人》：杜坎森的遗体。铁杖骑士团的死灵法师瓦丽娜想买去当不死的苦力，边区兵要砍头示众，他的小儿子古尔赞·熊心要接遗骨回去，掌管城防的伯爵联盟首领卡莱昂·黑塔限天亮前运出城。兽人的葬法叫归尘礼：拆骨、焚烧、把骨头磨成粉，这样死灵法师就唤不起来。
- 第二幕《再没人见过的矮人》：进矮人故道（玛瑙之门、死铁道）。山里的发现：兽人是最古老的先驱精灵在作坊里造出来的（精灵主将杜卡涅尔，就是兽人传说里的造物主杜坎尼尔）。
- 第三幕《郁金香底下的大公》：阿登·天枪大公 1443 年死在皇宫，对外说是和皇帝决斗，其实背上有一道窄刀口，是王座厅里第三个人从背后捅的，遗体埋在皇宫花圃底下。月党和玫瑰党是紫丁香战争里争皇位的两边。巴兹伍德是替皇帝管密探的侏儒，蒂尔达是他的手下。
- 第四幕《诸神之王》：穿过深林（妖精的地界，愚者亲王、黑枝亲王）去精灵故土阿伦蒂尔，找诸神之王卡斯特洛斯。壁画说明他早在“灰烬之日”就为挡住大火死了（精灵叫他卡斯特拉尔）。出林时外面已是 1472 年。
- 终章《卡斯托纳斯，又一次》：古尔赞带兽人回来。要决定神王的死讯怎么说，空出来的神位归谁（长子阿德安，凭功劳封神的科琳，还是空着）。

**同伴**：乌什卡（烂刀氏族的年轻兽人女子，懂葬仪，说话直，谈骨头像木匠谈木料）；阿坦（十六岁的小祭司，守着神王的破庙，盼“银龙再临”）；妮克西（地鹰氏族的地精商贩，东家是愚者亲王，精明，爱算计）；加莱尔·守昔者（精灵编年史家，从容，问话总问在点子上）；贝尔格拉克·穴居者（科琳的老伙伴，红宝石矮人，说话先报数目）。

**阵营**：承嗣派（名分定了，刀才收得回去）；试炼派（谁扛得动谁来扛）；无冕派（位子空着，天也没塌）。

**常见名词**：绿潮＝兽人大军南下的浩劫；冒险团＝受雇收复东坎诺的佣兵团；鸽座＝安本纳尔的皇位，此时在威克斯皇帝手里；摄政王庭＝人类信奉的一众神；归尘礼见上；血律＝在阿伦蒂尔说过的谎会变成手上的红痕；帷幕＝曾罩住深林的屏障，1443 年撤掉；晨星会＝夜里拜鸦王的秘密会社。
