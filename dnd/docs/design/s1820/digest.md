# 1820《泪尽》速览（用来核对事实和补交代，不要把这里的句子照抄进正文）

**前提**：灰元 1820 年，安本科斯特。十年前（1810），神谕之眼彗星在天上碎了，随流星落下的魔晶（达姆斯塔尔）一年比一年少，魔法在枯竭。同一年的黑火药叛乱推翻了帝国，法师贵族遭到清洗，共和国靠破魔弹（弹头掺了黑魔晶粉末，专破法术护盾）守着议会。玩家加入铸炉街上又老又穷的“迟到者公司”。这家冒险公司 1446 年立下章程，只有三条：护民之约“先护人，后算账”，守信之约“签了字的，就办到”，求真之约“去看，回来说”。往后十八年，公司接了四单大生意。

**关键概念**
- 别摇：布西拉尔学者阿尔瓦从南海的漩涡（通往别的位面的门，底下是“寰宇之根”）带回来的仙子，住在一只果酱罐里。她把人情当账记，对她说“谢”就等于认了一笔欠账。她扇翅膀的声音就是开门那把音叉的频率。
- 合伙人：公司匿名的五成一大股东，就是共和国的德希尔德将军，也就是青铜龙阿赫特（哈赫普拉人拜的神）。1790 年他被专打龙鳞的炮轰下来，从此不敢飞。他把自己的败仗都说成“平手”。
- 复式账：破魔弹打得越多，法术越弱。黑魔晶把魔力导去了别的位面，有人在那一头收。
- 血税和蓝血：抽法师的血当魔晶用。
- 机械人和芯核：机械人胸口的芯核是刻了纹路的魔晶。醒过来的机械人在法律上仍是财物。文森顿的“魂炉”烧的就是醒着的芯核。礼拜三是公司账上的“十四号器材”，一台醒着的机械人。
- 碎片：揭秘教会的圣物，藏在阿兰蒂尔塔的地窖里，会发声。它翻来覆去说的那句话有三种读法：把门关上，门关着，门是从里面关的。它当中的黑方块是天门的钥匙。
- 第二次阿兰蒂尔大峰会（1834）：各国商量破魔弹和剩下的魔力怎么分。三份草约：配给、禁令、特许。
- 天门：妖精界那片海的尽头，天国的门，没有把手，是里面的人闩上的。

**各幕**：序章（五种出身）→ 第一幕《收成》（护送公务法师给要公投的地区催熟麦子，“暂缓名单”，康威尔广场那一枪）→ 第二幕（东坎诺的铁路线，法师的血账，雅米娜的复式账）→ 第三幕（巨魔湾：追奴合同和帮奴隶逃跑的暗线，文森顿的魂炉，机械人算不算人的官司）→ 第四幕（大峰会，调查庭，洛伦特王冠里的精灵国太伊奥瑞尔，同合伙人摊牌）→ 终章（出海进漩涡：妖精界的海、抽气船、平潮庭、阿赫特、崩塌之城、天界浅滩、天门，最后一次团务会决定签哪一份约）。

**公司的人**：埃塔·斧砧（白发矮人秘书，说话先报数目）；布拉·铁颌（林墙兽人老兵，黄铜下巴，共和国欠她十一个月军饷）；礼拜三（见上，说话带“（陈述。）”一类括号）；吉列姆（三等公务变化师，果农的儿子）；娜尔雯·望月（月精灵修女，记了一百五十多年碎片的鸣声）；蒂尔妲·双扳（话多的侏儒奇械师）；诺罗·数浪（半身人领航员，叙述里不用“他”“她”）。

**声望各方**：共和国；王冠与魔杖（洛伦特宫廷和旧法师贵族）；特许商（卡拉桑尼、银行团等）；揭秘教会；互助社（工会、废奴派、醒着的机器）；南岸（卡尔希尔、领航员、哈赫普拉）；合伙人。
