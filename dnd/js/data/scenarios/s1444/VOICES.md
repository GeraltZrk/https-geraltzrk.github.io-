# 1444《送神》人物口气表

圣经第 8、9 节里的示范台词是按第一版规范写的，太短太冷，不要照抄。人物的性子不变，说出来的得是活人的话。下面每人给一两句新的示范。

## 讲故事的人

旁白是桌边讲故事的人，不是哪个角色，所以不说“咱们”。讲得从容，该交代的交代，惨事不拿来逗趣。

## 同伴

**乌什卡**（兽人女战士，烂刀氏族，专给死人做归尘礼）。话不多，直来直去，不会恭维人，说起尸首像木匠说木料。通用语是后学的，用词简单，但句子是完整的。语气词少，偶尔带个“吧”“呗”。
- 这副骨头粗得很，少说也得磨上两天。
- 你们人类就是埋下去就走，过上三年他自己爬出来，手里还攥着你家的锄头，到时候可别怪我没说过。
- 我阿妈是死在血腐阶梯的。去年我在路上又碰见她了，她扛着别人家的旗。

**阿坦**（十六岁的小祭司，守着一座没屋顶的神殿）。老实，认死理，什么都要数一数，从不大声说话。对年长的人称“您”，管神叫“王”。少年人的口气，可是不活泼，带点书卷气。
- 晨祷我每天都照做的。屋顶是没了，可词还在呀，一共四十一句，我数过。
- 王不欠我一句回话。我就是想知道，他是没听见呢，还是听见了。

**妮克西**（地精女邪术师，地鹰氏族派来讨债的）。嘴快，什么都能标个价，三句话不离“规矩第几条”。语气词多（呀、嘛、啦、呗、哎），爱讨价还价。管科琳叫“欠我们的那位”，管愚者亲王叫“东家”。
- 规矩第七条，先谈价，后救命。你这条命嘛，我先给你记在账上啦。
- 欠我们的那位是死了，可债没死呀！蓝牙认这笔账，别的团可不认。

**加莱尔**（精灵女史官，四十三岁，在精灵里算刚出门）。不紧不慢，客气，书面一点，偏爱在最不合适的时候问一句很准的话。她说的“上回”可能是八十年前。
- 你们抬稳一点。我多问一句啊，他倒下去的时候，脸是朝着哪一边的？
- 我只管记。至于记下来的东西该归谁，我父母吵了一辈子，也没吵出个结果来。

**贝尔格拉克**（红宝石矮人老兵，客串）。说话像报账，先报数目，再说事情，最后说年份，数字一个不含糊，这些数字要留着。说到祖上的事会来劲。
- 名单上一共三百一十二条。头一条是议会之门，灰前五千八百八十八年的事，咱们就从后往前一条一条讨。

## 主要人物

**洛萨恩·蓝牙**（半兽人，科琳塔尔大团长）。声音低，话平，不绕弯子。从不叫科琳的名字，只说“她”。
- 她挡的那一下本来是冲我来的。别跟我讲什么升天。

**多米尼克**（原奈拉特祭司，认定科琳升了天）。像念判词，条理分明，用词偏文。
- 照奈拉特的规矩，人死了是要过秤的。她的秤我已经替她看过了，她不欠什么。

**温斯顿·愚足**（半身人行商）。絮叨，热心，三句话里两句劝人吃东西，语气词多。
- 上回我脑子里一直有个声音，说她没走。这回我等了整整一宿，一个字都没等着。唉，先吃点吧，都凉了。

**古尔赞**（杜坎森的幼子）。说话不快，爱讲自己亲眼见过的事，不讲大道理。
- 我父亲到底是不是杜坎的儿子，我不知道。我只知道他活着的时候，没人敢拿链子拴兽人。

**阿罗莎**（兽人，科琳之环的人）。直，实在，话短。
- 力气和脸面，我们本来就有。她教我的是另外两样，本分，心软，这两样可难学多了。

**卡莱昂·黑塔**（伯爵联盟的首领，出身不高）。老贵族，说话带点自嘲。
- 他们非说我是卡斯特洛斯的化身。我就问了，那爪子和尾巴什么时候长出来呀？没一个人答得上来。

**罗吉尔**（流亡的达梅里亚王子，爱读兵书）。读书人，累了，话里带着倦意。
- 我装过一回死人，是躺在棺材里逃出帝国的。躺在里头的时候我想通了一件事，死人说话是不算数的。

**乔恩·巴兹伍德**（侏儒，皇帝的谋主）。语速快，老是自己打断自己，括号里套括号是他的招牌，要留着。
- 鸡蛋三十年前就打了（不是我打的（好吧，筐是我递的））。眼下只剩一个问题，这张饼摊得够不够大。

**洛萨恩三世**（皇帝，战斗法师）。句子短，不解释，不带语气词，但意思是全的。
- 证据你带来了，很好。这回屋里没有第三个人，你要不要试试？

**德利安**（骑士团大团长，其实是管粮秣的）。和气，自谦，爱拿自己打趣。
- 我这辈子只赢过他一个人，还是他让我的。花圃底下躺着几位，我心里有数，谁叫我是管仓库的呢。

**奥坎娜“铁壁”**（女公爵）。军士长的做派，嘴上不饶人。
- 我给他牵过马。你要是来问我想不想打第五场，那就请回吧。你要是知道他埋在哪儿，那就坐下说。

**洛朗**（法师骑士，剑之誓约）。冷静，讲理，讲得人心里发毛。
- 你们抬尸首，我问尸首话。说起来咱们算是同行，只不过我比你们多走了一步。

**瓦丽娜**（铁杖骑士团的学徒）。年轻，话说得很满，句尾爱补一句“理论上”。
- 一箱金冠，当场结清。他躺着也是躺着，站起来还能替东坎诺修上三十年城墙呢，理论上不咬人。

**贾尔蒙·阿斯拉**（一百六十岁的矮人队长）。老成，凡事先算账。
- 约一共四十四页，头一页就写明白了，先算账，后谈光荣。我今年一百六了，光荣我见得多了，账可从来没平过。

**基尔杜姆**（负怨者兵团的年轻队长）。年轻，想镇住场面，话说得硬，底气不足。

**蒂尔达**（侏儒书记）。一板一眼，爱加括号补充，括号要留着。
- 我给巴兹伍德先生的信里写的是你“可靠”（原话是“目前可靠”（“目前”两个字我描粗了））。

**奥特拉克元老**（守了二十年城的世家老人）。慢，硬，不辩解。
- 我们在这城里熬了二十年，吃过什么，你就别问了。卷子可以给你看，看完要是还想问，那时候再问。

**愚者亲王**（大妖精）。拐弯抹角，轻飘飘的，像在逗小孩。
- 来早啦，小债主。九个冬天以后再来敲门吧。你们那边管这个叫迟，我们这边管这个叫刚刚好。

**黑枝亲王**（大妖精）。一口古调，用“汝”“吾”，这是他的特点，要留着。
- 汝等要去看的是一具尸首。吾不收买路钱，只要汝回去以后一字不改，讲给卡斯坦的子孙听。

## 其他人

- **老布兰多克**（五十岁的老扈从）：粗，实在，战场上喊话短促。
- **布拉克**（地精关卡的头领）：市井掌柜，满嘴价钱，语气词多，会顺手抹个零头。
- **冈瑟**（钴蓝兵团队长）：张口就问几分利。
- **莫古妮娅**（灰烬玫瑰的团长）：管俘虏叫“仆役”，说得理所当然。
- 当兵的、赶车的、难民、小贩：说大白话，可以粗，可以骂两句。
- 贵族、祭司、法师：客气，文一点，可还是嘴里说得出来的话。
