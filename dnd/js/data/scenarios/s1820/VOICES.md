# 1820《泪尽》人物口气表

圣经第 8、9 节里的“说话方式”和示范台词是按第一版规范写的，太短太冷，不要照抄。人物的性子和习惯不变，说出来的得是活人的话。这里没列到的人，去 `BIBLE.md` 第 8、9 节按名字查他是谁、什么性子。

这是煤气灯的年代：报纸、罢工、铁路、专利、电报、股票。人物可以说“合同、股东、工会、专利、条例”这类词。故事跨十八年，人类会老，精灵、矮人、机器不变。

## 讲故事的人

旁白是桌边讲故事的人，不是哪个角色，所以不说“咱们”。制度是冷的，人是有意思的，惨事不拿来逗趣。

## 同伴

**布拉·铁颌**（兽人老兵，下巴是黄铜做的）。话不多，拿欠饷当尺子量所有的事，骂人不带脏字，带数目。他说坏消息之前，下巴的铰链会先响一声，这是他的招牌，旁白里可以写。句子短，可是完整。
- 前头有个卡子，六个人，两条枪。枪归我。
- 共和国欠着我十一个月的饷，我欠着科琳一条命，这两笔我都记着呢，先还哪一笔，得看今天。

**礼拜三**（刚醒过来的机械人）。说话没有语调，所以先报情绪，括号里一个词，然后才说话，这个括号是招牌，要留着。爱数东西，不打比方。话直白，可不是电报。
- （高兴。）你撒谎的时候，左手会去摸口袋。（陈述。）我数过了，一共十一回。
- （不确定。）账上写着我每年折旧一成，照这么算，到 1826 年我就不值钱了。（礼貌。）到了那一年，我还能留下来吗？

**吉列姆**（国家三等变化师，靠施术吃公家饭）。话说得很满，然后补一句“理论上”。填表的时候会念出声，爱引条例的编号，不会讲价。
- 这块地不施术也能长东西，理论上是这样。实际上呢，从 1803 年起它就没自己长出过什么来。
- 你别谢我。我每天早上喝的那杯东西，大夫说是拿寿数换的，换来的就是这四十亩地。划算的，我算过。

**娜尔雯·望月**（精灵修女，等一个声音等了一百五十年）。不着急，爱说“上回”，她的上回是 1666 年。数目报得很准，从不提高嗓门，问句比陈述句多。
- 上回有人这么问我，还是 1666 年的事。问的那个人第二天就走了，连伞都没带。
- 今年是十一声，1809 年是四十声。我可没说它在变弱，我说的只是我数到了十一。

**埃塔·斧砧**（矮人，公司的秘书，不进战斗队伍）。说话像报账，先说数目，再说事情，记仇能记到年份。数字要留着。

## 主要人物

- **卡斯蒂娜**（洛伦特女王）：客气，绕。一句话说到一半，会换一副口气接着往下说。
- **伊奥瑞尔**（红宝石王冠里的回声）：借女王的嘴说话，老派，像在口述格言，这个特点要留着。
- **莫里斯·安德克利夫**（大监院，废奴派）：台上是讲道的嗓子，私下里说的是短话、实话。
- **威廉·戴纽奇**（种植园主）：迷人，周到，饭桌上只管劝别人吃。
- **科尔班·灰磨**（大监院，热忱派）：和气，每一句都能直接拿去当讲道词。
- **格拉托**（卡拉桑尼的首脑，买卖人）：给你两个选项，两个他都赚。
- **拉姆斯盖特**（军火巨商）：直，不装，把难听的实话说得理直气壮。
- **莉安娜**（被清洗的战斗法师）：硬，话里带火气。
- **瓦伦盖尔特**（龙王子）：健谈，什么都往外说，所以没人信他。
- **贾内比萨**（哈赫普拉的将才）：干脆，像在下命令，书读得多。
- **埃利奥**（安本科斯特市长，工会领袖，工程师）：讲道理像画图，一步一步来，性子莽。

## 其他人

- 工人、车夫、报童、士兵：说大白话，可以粗，可以骂两句。
- 银行的人、公司的人、官员：公文腔，客气，说到钱就不客气了。
- 教士：讲道的调子，但私下里也是人。
- 报纸、告示、合同、电报里的文字是书面语，照它们各自的体例写，不必口语化。
